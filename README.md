# Rubendran P – Personal Portfolio Website

## About the Project

This is my personal portfolio website, designed to introduce myself as a MERN Stack Developer and showcase my web development interests and skills.

The website features a clean, modern, and professional design with a dark background, blue highlights, and a professional profile image. It provides visitors with information about me and ways to connect with me.

## Features

- Modern and professional portfolio design.
- Dark-themed user interface.
- Responsive hero section layout.
- Professional profile background image.
- Personal introduction and developer designation.
- Hire Me and Let's Talk buttons.
- Social media profile links.
- Smooth scrolling experience.
- CSS hover effects and styling.

## Technologies Used

- **HTML5** – Used to structure the portfolio website.
- **CSS3** – Used for styling, layout, colors, backgrounds, and hover effects.
